## 2. 확장 주제 예시

주제는 팀별로 자유롭게 선정해도 좋습니다. 주제 선정이 어려울 경우 아래 내용을 참고하세요

### A. 유닛 강화(업그레이드) 시스템
- **[최소 범위]** 레벨 2까지 올릴 수 있다. 레벨별 스탯을 표에서 읽어 적용하고, 관리 메뉴에서 비용을 내고 올린다.
- **[여유 있으면]** 3레벨까지 · 누적 투자 기준 환불 · 레벨에 따른 외형 변화
- 데이터 : 레벨별 스탯 표를 새로 만들고 `UnitTable` 에서 유닛과 묶어야 함

### B. 전투 연출 강화 (투사체 · 피격 표현)
- **[최소 범위]** 유닛이 투사체를 발사하고, 대상에 닿는 순간 피해가 들어간다.
- **[여유 있으면]** 오브젝트 풀로 재사용 · 크리티컬 시 다른 색/크기 · 적 사망 연출

### C. 상태이상 시스템 ※ 범위 주의
- **[최소 범위]** 둔화 1종. 맞은 적의 이동이 느려지고, 지속시간이 끝나면 원래대로 돌아온다.
- **[여유 있으면]** 지속 피해 · 중첩 규칙 · 적 머리 위 아이콘 표시

### D. 경제 심화
- **[최소 범위]** 조기 호출 보너스. 준비 시간을 남기고 웨이브를 부르면 남은 시간에 비례해 광물을 받는다.
- **[여유 있으면]** 웨이브 클리어 시 이자 · 소모품 상점

### E. 유닛 · 적 계열 확장
- **[최소 범위]** 새 적 2종을 **표에 행만 추가해서** 넣고, 새 조준 방식 1종을 클래스로 추가한다.
- **[여유 있으면]** 새 공격 방식(관통·연쇄 등) 1종 · 유닛 1종 추가
- 포인트 : **기존 코드를 얼마나 적게 고치고** 추가할 수 있는지가 이 주제의 핵심입니다.

## 3. 작업 규칙 참고

### 3.1. 설계 원칙

#### 수치는 코드가 아니라 표에 둔다
새로 만드는 기능의 밸런스 수치는 `.tsv` 또는 `config.json` 으로 뺍니다.
코드에 `if (level == 2) damage = 34;` 같은 하드코딩을 남기지 마세요.

#### 실수가 조용히 숨지 않게 한다
- 인스펙터에 연결했어야 할 것이 비어 있으면 **그냥 예외가 나게 둡니다.** `if (x == null) return;` 으로 감싸서 "동작은 하는데 아무 일도 안 일어나는" 상태를 만들지 마세요.
- 표에 있어야 할 데이터가 없으면 로그로 알립니다.
- 다만 **사용자 입력**(빈 곳 클릭, 광물 부족)처럼 실패가 정상인 경우는 정상적으로 처리합니다.

#### 책임을 나눈다
기존 코드가 어떻게 나뉘어 있는지 보고 따라가세요.

```
BoardMap        타일이 지금 어떤 상태인가        (상태 보관)
PlacementSystem 그래서 지어도 되는가             (규칙 판단)
EconomyManager  광물을 얼마나 갖고 있는가        (자원)
```

새 기능도 "이건 누구의 일인가"를 먼저 정하고 시작하세요.

#### 아래층은 위층을 모른다  
`Enemy` 가 `HUD` 를 직접 부르면 안 됩니다. 이벤트로 알리고, 듣고 싶은 쪽이 구독합니다.

### 3.2. 코드 규칙

- 네임스페이스 : `Study.MiniDefence` (기존과 동일)
- 새 파일은 **팀 폴더 아래**에 만듭니다 → `15. Mini Defence/9x. {팀명}/`
- 기존 파일 수정은 **최소한으로**. 어떤 파일을 왜 고쳤는지 제출 문서에 적습니다
- 주석은 한국어로, "무엇을"이 아니라 **"왜"** 를 씁니다
- UI 없이 기능을 확인할 수 있는 **테스터 클래스**를 하나 만듭니다 (`WaveTester` · `UnitTester` 참고)

### 3-3. 협업 규칙

- 브랜치 : 자유롭게 해보세요
- 커밋 : 한 커밋에 한 가지 변경. 메시지는 한국어로 무엇을 했는지
- `main` 에 직접 push 금지. 병합 어려울 경우 저한테 물어보세요

### 자주 하는 실수

- **표에 컬럼을 추가했는데 값이 안 들어옴** → DTO 클래스의 필드 이름과 표 헤더가 정확히 같아야 합니다
- **씬에서 아무 반응이 없음** → 인스펙터 연결을 빠뜨렸을 확률이 높습니다. 콘솔의 예외를 먼저 보세요

- **표를 고쳤는데 반영이 안 됨** → `StreamingAssets` 안의 파일을 고쳤는지 확인하세요
